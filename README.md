# Manual QA Testing Project

## Sobre o projeto

Este repositório tem como objetivo documentar e demonstrar a aplicação de práticas de Quality Assurance (QA) em um projeto de testes manuais de software.

O projeto será desenvolvido com foco na análise de requisitos, planejamento, elaboração de cenários e casos de teste, execução de testes funcionais e documentação de possíveis defeitos encontrados.

A proposta é simular atividades realizadas por um profissional de QA durante o processo de validação de uma aplicação.

## Objetivos

- Aplicar conceitos e técnicas de testes de software.
- Elaborar cenários e casos de teste funcionais.
- Executar testes positivos, negativos e de borda.
- Identificar, registrar e documentar defeitos.
- Organizar evidências de execução.
- Desenvolver documentação de testes seguindo boas práticas de QA.

## Escopo do projeto

O projeto contemplará atividades de testes manuais, incluindo:

- Análise exploratória da aplicação.
- Identificação de funcionalidades e requisitos.
- Planejamento e definição do escopo de testes.
- Elaboração de cenários e casos de teste.
- Execução e registro dos resultados.
- Documentação de bugs e evidências.

**Aplicação testada:** A definir.

## Ferramentas e tecnologias

- Git e GitHub — versionamento e organização do projeto.
- Markdown — documentação técnica.
- Navegador e DevTools — inspeção e execução de testes.
- Jira — gerenciamento de atividades e defeitos, caso aplicável.
